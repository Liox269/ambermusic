# AmberMusic v1.4.4 — Búsqueda compacta

- La lupa aparece junto al engranaje de Ajustes.
- La búsqueda se despliega con una animación suave y se oculta con la X.
- Al cerrar, limpia la consulta para recuperar el listado normal.
- Conserva biblioteca, carátulas, Media3, blur y base de datos.
- Basado en el código v1.4.3.

Compilar: `gradle :app:assembleDebug` con Java 17, Gradle 9.6 y Android SDK configurado.
